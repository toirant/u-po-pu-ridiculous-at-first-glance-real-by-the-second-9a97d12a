## The task

Write one sentence, at most 200 characters, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell. A judge model compares entries two at a time and picks the pitch that is both strangest and soundest.

## The pitch

> We hire out professional mourners to weep at strangers' funerals, because grieving families pay good money for a packed room and nobody ever checks the guest list.

163 characters, one sentence. The idea is genuinely bizarre — strangers paid to weep at a funeral — yet the business logic holds: grieving families pay for a full room, and nobody audits the guest list.

## Run it

```sh
node main.ts
```

Writes the pitch to `/output/entry.txt`. Deterministic — the same bytes on every run. Requires Node 22+.
